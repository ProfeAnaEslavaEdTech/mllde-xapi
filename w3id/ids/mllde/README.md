# /mllde/

Permanent identifiers for the **MLLDE** xAPI vocabulary and Profile — voice-based
language-learning measurement aligned to the CEFR (Companion Volume, 2020).

- `https://w3id.org/mllde/` → <https://profeanaeslavaedtech.github.io/mllde-xapi/> (registry)
- `https://w3id.org/mllde/profile` → the machine-readable xAPI Profile (JSON-LD)

Documentation: <https://profeanaeslavaedtech.github.io/mllde-xapi/>
