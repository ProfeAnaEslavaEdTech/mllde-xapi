# w3id.org/mllde

Persistent identifier namespace for **MLLDE** (Mobile Language Learning Design
Environment), an xAPI vocabulary and Profile for measuring voice-based language
learning against the CEFR descriptor scales (Companion Volume, 2020).

- **Redirects to:** https://profeanaeslavaedtech.github.io/mllde-xapi/
- **Maintainer:** Ana Eslava-Graterol (Universitat Politècnica de València)
- **Licence:** CC BY 4.0
- **Status:** 302 (temporary) while the vocabulary is finalised; will move to 301 when stable.

`https://w3id.org/mllde/profile` content-negotiates to the machine-readable
xAPI Profile (JSON-LD); all other paths resolve to the human-readable registry.
