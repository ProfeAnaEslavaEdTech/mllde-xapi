MLLDE xAPI IRI Registry

Identificadores persistentes para medir el aprendizaje de lenguas por voz, alineados a las escalas del MCER (Companion Volume 2020). Los verbos de ADL se reusan en su forma canónica http://; los términos propios MLLDE viven en https://w3id.org/mllde/.

https://w3id.org/mllde/ext/help-requestObject: what was asked + resolution strategy (defined-in-target-language, gloss, example…)
https://w3id.org/mllde/ext/content-refIRI/id of the target content point from the CEFR content inventory (pattern en.gram.<level>.* or en.voc.<level>.*). Ties a turn/item/card to the graded grammar point or vocab item it exercises. Added v0.6.
https://w3id.org/mllde/ext/level-decisionObject {from, to, evidenceCount, confidence, note} — MLLDE's demonstrated-level recalibration decision, carried on a verbs/progressed statement. Gated: accumulated evidence, asr-confidence >= 0.70, floors intelligibility AND interaction >= 4. Self-declared level (learner-set) is kept separately in ext/cefr-level. Added v0.6.
https://w3id.org/mllde/ext/learning-targetObject {cefrLevel, type: grammar|vocab|sound, pointId} — the i+1 target the tutor teaches, carried on a verb/adapted statement. pointId references the content inventory (ext/content-ref). Added v0.6.
https://w3id.org/mllde/ext/measure-modelString/id — the measurement model that scored this session (the evaluator's measure_model). Kept for GDPR (interim model must also be no-train) and comparability: sessions scored by different models are NOT mixed in aggregates. Minted v0.8.1 (audit demand).

Extensiones de resultado

IRIGuarda / función
https://w3id.org/mllde/ext/rubric-scoresObject keyed by rubricCategories IRIs, integer bands 0-10 read against the level descriptor (pass = band>=6; floors intelligibility AND interaction >=4). The Cambridge 0-5 view = round(score/2), a reporting lens only. (Corrected v0.8.1: the earlier 1-3 wording was a v0.5 residue.)
https://w3id.org/mllde/ext/phoneme-scoresArray of { ipa: string (broad transcription), score: 0–100, confidence: 0–1, acceptedVariants: [ipa] } — acceptedVariants encodes legitimate variation (e.g. seseo/distinción); tier 3 until GOP or vendor scorer is integrated
https://w3id.org/mllde/ext/asr-confidence0–1 transcript confidence for the scored audio
https://w3id.org/mllde/ext/turn-latency-msMilliseconds from prompt end to learner speech onset — cognitive-load proxy
https://w3id.org/mllde/ext/retriesRetry count to completion (non-punitive mastery loop)
https://w3id.org/mllde/ext/grammar-errorObject: category + example + handled-by (pedagogicalActions IRI)
https://w3id.org/mllde/ext/prosody-scoresObject: { intonation, rhythm, stress } — suprasegmental measures kept as SEPARATE lines, anchored to cefr/scale/prosodic-features; never merged into phoneme-scores. Tier 3 (bespoke GOP) / tier 2 (vendor). Minted v0.4 for AE's Pronunciation Model v1.
https://w3id.org/mllde/ext/fluency-measuresObject: { speechRate (syllables/sec), pauseCount, fillerCount, selfCorrections } — fluency measures, tier 2 (from ASR timing). Onset latency stays in ext/turn-latency-ms. Minted v0.4 for AE's Pronunciation Model v1.
https://w3id.org/mllde/ext/phoneme-accuracyNumber 0–100 (Phoneme Accuracy) — preferred granular form of phoneme-scores
https://w3id.org/mllde/ext/stress-accuracyNumber 0–100 (Stress Accuracy)
https://w3id.org/mllde/ext/rhythm-scoreNumber 0–100 (Rhythm Score)
https://w3id.org/mllde/ext/intonation-scoreNumber 0–100 (Intonation Score)
https://w3id.org/mllde/ext/speech-rateNumber ≥0 WPM (Speech Rate)
https://w3id.org/mllde/ext/pause-frequencyNumber ≥0 pauses/min (Pause Frequency)
https://w3id.org/mllde/ext/hesitation-rateNumber 0–1 ratio (Hesitation Rate)
https://w3id.org/mllde/ext/fluency-scoreNumber 0–100 (Fluency Score)
https://w3id.org/mllde/ext/intelligibility-scoreNumber 0–100 (Intelligibility Score — engine estimate; band decided by MLLDE)
https://w3id.org/mllde/ext/acoustic-confidenceNumber 0–1 (Acoustic Confidence — measurement reliability)
https://w3id.org/mllde/ext/item-scoreObject {itemId, drillType, correct: boolean, unaided: boolean, attempts} for a grammar-drill / warm-up item. Feeds rubric/grammar-accuracy. Objective mastery: a grammar point is mastered at >= 3/4 correct unaided. Added v0.6.
https://w3id.org/mllde/ext/srs-outcomeObject {cardId, outcome: known|repeat, prevIntervalDays, nextIntervalDays} — spaced-repetition result for a vocabulary-card. Objective mastery: a vocab item is mastered when nextIntervalDays >= 7. Added v0.6.
https://w3id.org/mllde/ext/effective-timeNumber >=0 minutes — effective interaction time in the session (voice/practice), NOT app-open time. Accumulates toward the >=80h HR/level 'passed' gate (anchored to CEFR/Cambridge guided hours). Carried on the per-session completed statement. Minted v0.8.1 (audit demand: the 80h gate had no IRI).
https://w3id.org/mllde/ext/srs-scheduleObject {cardId, nextReviewDate, intervalDays} — the spaced-repetition SCHEDULE for a vocabulary-card (companion to ext/srs-outcome, which carries the outcome). Practice-loop signal, never a competency band. Minted v0.8.1 (was 'pending mint').
